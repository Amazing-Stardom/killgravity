# Release v1.0.0 (2026-11-01)

Initial public open-source release of **killgravity**.

## Highlights

- **Real-Time I/O Spike Detection**: Monitors `/proc/diskstats` for write surges (>500 MB/s or configured threshold) to catch runaway dump loops in 1–2 seconds.
- **NVMe SSD TBW Endurance Protection**: Stops repeated 8–16GB crash dumps from destroying SSD flash endurance and burning through 200GB+ of storage.
- **Surgical Process Matching**: Specifically targets `antigravity-ide`, preserving background agent CLIs, hubs, and dev tools without false positives.
- **Dynamic Version Auto-Discovery**: Auto-detects IDE binaries across `/opt/antigravity-ide*` and `$PATH` to ensure resilience across IDE updates.
- **Unified Single-Script Installer (`install.sh`)**: Supports rootless user installation (`./install.sh --user`), system-wide installation (`sudo ./install.sh --system`), and clean uninstallation (`./install.sh uninstall`).
- **All-in-One Management CLI (`killgravity`)**:
  - `status`: Comprehensive live dashboard of service state, target PIDs, and NVMe write rate.
  - `enable` / `disable`: Manage systemd auto-start on boot or login.
  - `start` / `stop` / `restart`: Real-time service control.
  - `threshold [VALUE]`: View and dynamically adjust trigger speed (e.g. `500M`, `1G`, `1000000`).
  - `time [interval|cooldown|delay]`: Configure polling frequency and post-restart cooldowns.
  - `target [PATTERN]`: Set custom process matching regex.
  - `auto-restart [on|off]`: Toggle automatic relaunching of the IDE with `--disable-crash-reporter`.
  - `kill`: Emergency manual termination of runaway dump-writing processes.
  - `clean`: Purge leftover crashpad (.dmp) and core dumps.
  - `test`: Run diagnostic probe on diskstats reading and process matching.
  - `logs [-f]`: Follow live journal logs.
- **Systemd Coredump Suppression**: Drop-in configuration (`99-killgravity.conf`) to stop systemd from writing multi-gigabyte crash dumps to disk.
- **MIT Licensed**: Completely open source.
