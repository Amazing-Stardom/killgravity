# Release v1.1.0 (2026-11-01)

## What's New in v1.1.0

### 1. Antigravity IDE Native Extension (`ide-extension/`)
- Real-time disk write rate ticker directly in the editor status bar (`$(database) 0.25 MB/s`).
- Color-coded safety thresholds: Neutral (< 150 MB/s), Warning Yellow (> 150 MB/s), and Critical Red on crash dump surge trip.
- Top editor toolbar icon (`$(shield)`) for 1-click status checking matching Antigravity layout.
- Interactive QuickPick control menu: toggle background guard service, clean dump files, view active PIDs, and trigger emergency kill.
- 100% powered by the main script (`killgravity`) with zero hardcoded metrics or duplicate logic.

### 2. Main Engine & CLI Enhancements
- `--json` / `-j` support across `killgravity status` and `killgravity sample`.
- Fast non-blocking sampling (`sample --json`) utilizing atomic runtime state caching in tmpfs (`/tmp/killgravity-live-<uid>.json`).
- Process termination signal resilience: ignores SIGHUP/SIGPIPE during process tree teardown so killing parent trees never interrupts the kill loop mid-execution.

### 3. Release & Packaging Automation
- GitHub Actions workflow automatically packages and attaches the Antigravity IDE Extension `.vsix` alongside the release tarball and SHA-256 checksums.
- `install.sh` automatically installs and links the IDE extension.
- Pre-release audit suite updated to 22 automated security and syntax checks.
