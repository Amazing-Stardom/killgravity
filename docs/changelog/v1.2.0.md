# Release v1.2.0 (2026-11-01)

## Summary
Release **v1.2.0** brings a major performance and reliability re-architecture to **killgravity**, porting the core watchdog engine to Go, eliminating false-positive surge detections during terminal builds, and packaging the Antigravity IDE extension (`.vsix`) as an official release asset.

---

## What's New in v1.2.0

### 1. High-Performance Go Engine
- Re-implemented core CLI, watchdog daemon, process discovery, and `/proc/diskstats` sampling in pure Go using only the Go standard library.
- Status and fast-sampling response times reduced from ~50ms to **<2ms**, enabling instantaneous IDE extension telemetry with 0.0% CPU overhead.
- Compiles into a single standalone static binary (`bin/killgravity`) with zero external runtime dependencies.

### 2. Terminal Build & Interactive Shell Exclusion
- **Terminal Shell Filtering**: Inspects `/proc/<pid>/exe` and `argv[0]` to strictly exclude interactive terminal shells (`bash`, `zsh`, `sh`, `fish`, `dash`, `tmux`, `screen`).
- **Dual-Gate I/O Attribution**: Separates system-wide disk writes (`/proc/diskstats`) from target IDE writes (`/proc/<pid>/io` `write_bytes:`).
- **Compile/Build Safety**: Intensive compile operations (`cargo build`, `npm run build`, `make`, `gcc`, `go build`, `docker`) executed inside the integrated terminal no longer trigger false-positive disk surges or terminate the IDE.
- Only terminates processes if target IDE write rate itself surges or verified crashpad dump files (`.dmp` / `core.*`) are being written in pending crash directories.

### 3. Antigravity IDE Extension Distribution
- Updated GitHub Actions release workflow (`.github/workflows/release.yml`) to automatically package and publish the Antigravity IDE extension (`killgravity-v1.2.0.vsix`) alongside binary archives and SHA-256 checksums.
- Fixed stuck progress notification by streamlining status menu popups.

### 4. Consolidated Release Pipeline
- Consolidated multi-step release scripts into a single unified Python helper in `scripts/release.sh`.
